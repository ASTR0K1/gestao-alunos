Criar acesso do coordenador

Só o coordenador regista, pesquisa e altera os dados dos alunos. Escolhe o teu nome e um código de acesso.

Pelo menos 6 caracteres.

Onde fica guardado o código?

No servidor, no ficheiro bd/coordenador.txt, de forma cifrada: não dá para ler o código a partir dele. Se o esqueceres, quem tem acesso ao servidor apaga esse ficheiro e cria-se um acesso novo. Os alunos não são afectados.

Esqueci o código

O código não se recupera por aqui. Quem tem acesso ao servidor apaga o ficheiro bd/coordenador.txt e cria-se um acesso novo. Os alunos não são afectados.
